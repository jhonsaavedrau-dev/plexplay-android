# PLEX PLAY para Android

App Android de [PLEX PLAY](https://jhonsaavedrau-dev.github.io/portfolio-francais-c1-1/plexplay/): francés de A1 a C1 para el programa de Lenguas Extranjeras.

**Descargar:** [PLEX-PLAY.apk](https://github.com/jhonsaavedrau-dev/plexplay-android/releases/latest/download/PLEX-PLAY.apk)

Cada cambio en `main` compila y firma el APK y el AAB (para Google Play) con GitHub Actions y los publica en *Releases*.
